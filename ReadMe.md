📸 Image Randomizer App
A dynamic and interactive web application that displays themed images (cats, dogs, stars) and automatically refreshes them at timed intervals. This project was created as part of my COMP 10259 coursework.

🎮 App Description
Core logic for the Image Randomizer App.
This script manages:
- A 2D array of themed images
- Random image selection from each group
- Duplicate‑free image generation
- Countdown timer with color‑changing UI
- User‑controlled refresh interval (500–10,000 ms)
- Spin animation on image click
- Manual and automatic image refreshing
- Total image‑change counter
- Initialization of all event listeners on page load

🛠️ Tech Stack
- HTML / CSS / JavaScript
- DOM manipulation
- Timers (setInterval / setTimeout)
- Basic CSS animations

✨ Features
- Three themed image groups (cats, dogs, stars)
- Smooth spin animation on click
- Auto‑refresh with countdown
- Dynamic timer color indicators
- User‑defined refresh interval
- Manual randomize button
- Live counter showing total image changes

▶️ How to Run
- Clone the repository
- Open index.html in your browser
- - Use the controls to randomize images or adjust the refresh interval
